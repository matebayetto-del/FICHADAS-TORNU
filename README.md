# INMAC · Planilla de fichajes v6

## Resaltados
- Columna E en escala roja: cantidad de días `AUSENTE`.
  - 3–4: rojo muy suave
  - 5–7: rojo suave
  - 8–10: rojo medio
  - 11 o más: rojo fuerte
- Columna E en amarillo: posible ambigüedad por nombre o legajo.
- El amarillo tiene prioridad visual sobre el rojo, porque el vínculo debe revisarse antes de interpretar las faltas.
